# JavaScript Topic Practice Pack

Beginner-friendly JavaScript examples for the topics in the activity table.

## Run locally
1. Download/clone this repository.
2. Open any `.html` file in a browser, or use VS Code with the Live Server extension.
3. Each HTML file loads its matching JavaScript file with the same filename.
4. Most activities work offline. `Validation_using_API` needs an internet connection and depends on a public API.

## Activities
- Brief on JavaScript: data types, let and const, conditional statements, random numbers using a while loop
- Classes in JavaScript: this keyword, JS class, class inheritance, static methods
- Array sorting and mapping: sort/reverse strings, sort/reverse numbers, map an array, evaluate variables
- JavaScript in Detail: type conversion, search and replace, error handling, arrow functions
- JSON and JS Asynchronous: JSON, callbacks, promises, async/await
- Validation in JS: form validation, API validation, calculator

All activity files are placed directly in the repository root (no nested activity folders), with unique filenames suitable for uploading to GitHub.
